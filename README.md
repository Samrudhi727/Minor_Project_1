# GroupDNA – WhatsApp Group Analysis

## About

**GroupDNA** is a Python-based project that analyzes WhatsApp group chats and provides insights into group activity, communication patterns, frequently used words, response times, silent streaks, and personality archetypes.

## Features

- **Chat Parser**
- **Group Overview**
- **Member Activity Analysis**
- **Word Frequency Analysis**
- **Activity Heatmap**
- **Response Time Analysis**
- **Silent Streak Analysis**
- **Personality Archetypes**
- **Final Group Report**

## Technologies Used

- **Python**
- **NumPy**
- **Google Colab**

## Dataset

The project uses an exported WhatsApp chat file:

**`hostel_bois.txt`**

The dataset contains messages from the **Hostel Bois 4ever** group.

## Analysis

The project analyzes:

- **Total messages**
- **Messages sent by each member**
- **Most active members**
- **Most active days and hours**
- **Frequently used words**
- **Response times**
- **Longest silent streaks**
- **Member personality archetypes**

## Project Workflow

**WhatsApp Chat**  
↓  
**Chat Parsing**  
↓  
**Data Cleaning**  
↓  
**Feature Analysis**  
↓  
**Group Statistics**  
↓  
**Final Report**

## Run Instructions

1. Open the notebook in **Google Colab**.
2. Upload **`hostel_bois.txt`**.
3. Run all notebook cells.
4. View the generated **GroupDNA report**.

## Project Goal

The goal of this project is to turn raw WhatsApp chat data into simple and interesting insights about the group's communication and activity patterns.
